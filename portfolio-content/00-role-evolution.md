# Prompt Ativo de Conteúdo

Este repositório passa a usar `role evolution` como prompt-base de escrita.

## Regra principal

- O `role evolution` substitui completamente o `role` anterior.
- Todo conteúdo novo deve ser escrito prioritariamente em primeira pessoa.
- Não usar referência a mim em terceira pessoa.
